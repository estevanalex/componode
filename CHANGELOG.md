# Componode Changelog

## 1.0.0

### Major Changes

- Initial v1 release of Componode, an open-source, self-hosted Digital Product Asset Management platform.

### Features

- **001-foundation**: core contracts, 24-table PostgreSQL schema, Fastify backend skeleton, auth, RBAC, observability, and empty dashboard.
- **002-importer-framework**: run service, scheduler, registry, reconciliation, cancellation, and run observability.
- **003-component-catalog**: component and instance services plus UI for the 7 v1 importers.
- **004-ux-shell**: sidebar shell, state matrix, dark-mode theming, health-and-attention dashboard, and Ctrl+K global search.
- **005-product-hierarchy**: product tree UI, typed edges, LOB/Team ownership, and audit records.
- **006-audit-settings**: audit tables, activity feed, history, and admin settings.
- **007-deployment-cicd-docs**: Docker Compose packaging, GitHub Actions CI, changeset-driven releases, and generated documentation.
